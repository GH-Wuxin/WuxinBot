## s040 [calibration] 怎么分析一个玩家的bp结构

expected=self_and_domain actual=self_and_domain blocks=osu_domain:mods_core(4.7529), osu_domain:analysis_evidence(4.4171) injectedChars=154

### Baseline

```
想分析 BP 结构，先看几个维度：

**1. 星数分布**
高位 BP 的星数跨度大不大？是集中在某个区间，还是从低到高都有？集中说明打法单一，跨度大说明能力面广。

**2. Mod 占比**
HD、HR、DT、NM 各占多少？全是 DT 冲 pp 的，和混着 HDHR 的，打法思路完全不一样。

**3. 图型偏好**
跳图、串图、tech、speed 哪种多？光看标题和星数猜不准，但结合 mapper 风格和谱面特征能看出个大概。

**4. 年代分布**
BP 里老图多还是新图多？全是远古图说明可能退坑过或者没在追新，新图多说明还在活跃打榜。

**5. acc 水平**
高位 BP 的 acc 普遍高还是参差？普遍高说明稳，参差说明在冲难度或者状态波动大。

不过得说清楚，BP 结构只能反映"展示出来的成绩"，看不出练习过程、真实能力边界和失误原因。你要是给我一个具体账号，我可以帮你看看实际数据。
```

### KB

```
想分析 BP 结构，核心是看**高位成绩的分布和集中方向**，而不是单看总 pp 或 BP1。

几个切入点：

1. **Mod 占比**：BP 里 HD、DT、HR 各占多少？集中在一两种 Mod 说明打法有偏向，比如全是 DT 可能偏速度/读图，全是 HR 可能偏 acc 和稳定。
2. **星数跨度**：BP1 到 BP100 的星数梯度是平滑上升还是断层？断层说明可能突然冲了某张高星图，或者长期停在某个难度区间。
3. **acc 水平**：高位成绩的 acc 普遍高还是参差？普遍高说明稳，参差大说明容易在特定段落掉链子。
4. **图型分布**：跳图、串图、tech、speed 哪类多？能看出擅长什么、短板在哪。
5. **年代跨度**：BP 里有没有老图？全是新图说明近期活跃，混着老图可能是回坑玩家或一直保持手感。

不过得说清楚：BP 结构只能看出“展示出来的能力结构”，看不出练习习惯、失误原因这些。要更细的判断得看 recent 或者具体 replay。
```
