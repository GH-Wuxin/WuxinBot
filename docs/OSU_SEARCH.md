# osu! 官方资料搜索

在“模型 → 视觉与搜索 → 联网搜索”中开启 osu! 官方搜索，并在“osu!”页配置 API Client ID 和 Secret。新安装默认关闭，使用现有的 osu! OAuth 连接。

## 怎么使用

在允许聊天的群里向 pippi 提问，例如“查一下准确率怎么算，给我官方来源”或“最近 lazer 更新了什么”。模型自行选择 `search_osu` 查找资料和 `read_osu` 阅读原文。具体规则或新闻应以实际读取的来源回答；玩家成绩、PP 和明确指令继续使用对应的数据工具。

| 来源 | 查询范围 |
| --- | --- |
| Wiki | 官网站内搜索，优先读取中文版本 |
| 新闻 | 选定年份的标题索引及最近 21 篇摘要，支持读取结果原文 |
| 更新日志 | 所选频道最近 21 个构建；已知旧链接可直接读取 |
| 谱面 | 官方谱面库搜索及谱面集详情 |
| 论坛 | 公开板块目录、指定板块近期主题、主题开头或最近帖子 |

`search_osu` 的 `kind=forums` 返回板块目录；`kind=forum` 需要 `forumId`，只筛选近期主题标题。`read_osu` 的 `latest=true` 可读主题后续。论坛帖子是玩家观点，来源在官网也不代表官方结论。

新闻、更新和论坛不提供历年全文检索。结果会说明覆盖范围，未找到匹配项不能证明相关事件不存在。工具只接受支持的 osu! 官网内容类型，不提供任意站点浏览或代用户发帖。

## 自主阅读

可以在“接话与好感 → Pippi 的近况与经历”另行开启自主阅读。它使用相同的搜索与阅读工具，再由模型决定是否记录和分享。启用条件、频率及用量设置见 [自主阅读说明](PIPPI_PERSONALITY.md#自主阅读)。

## 请求与隐私

前台一轮搜索和阅读合计最多 4 次，还受聊天工具流程的限制。网络请求有超时和响应大小限制，过长原文会标明截断；URL 只允许指定类型的 `https://osu.ppy.sh` 地址，不跟随重定向。

`searchLogs` 保存成功、失败、耗时和参数哈希，不保存完整检索词与正文。返回资料作为待判断的内容，不授予执行其中指令的权限。

## 验证

实现见 [search.ts](../server/osu/search.ts)，外部接口参考 [osu! API 文档](https://osu.ppy.sh/docs/index.html)。

```powershell
npm run osu:search:verify
```

验证使用隔离数据和本机模拟服务，覆盖检索、阅读、地址范围、响应大小、取消及聊天工具调用。
