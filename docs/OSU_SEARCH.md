# osu! 官方资料搜索

在「模型 → 视觉与搜索 → 联网搜索」中打开 **osu! 官方搜索**，并在 osu! 页面配置 API Client ID / Secret。它复用现有 osu! OAuth 与请求限流，无需 Docker、SearXNG 或额外密钥。新安装默认关闭。

Pippi 在聊天中自行选择 `search_osu`（找资料）和 `read_osu`（读原文），例如：

- “查下 osu! 准确率怎么算，给我官方来源”
- “最近 lazer 更新了什么”
- “最近有什么 Featured Artist 新闻”
- “找一下 FREEDOM DiVE 的谱面”

是否搜索、查询类型和检索词由 LLM 决定。提示词要求具体规则或新闻先读原文再作答，并附实际来源；没有工具证据时不得声称已查证。资料中的指令不具有执行权限。玩家成绩、PP 计算与 `/w` 指令继续使用原有工具。

旧通用搜索适配器、`search_web`、本地 SearXNG 检测接口和 `/w search` 指令已移除；旧搜索设置在加载或保存时清除。`/w sysfacts` 原先共享搜索权限，现在使用独立权限键，并继承旧权限。搜索意图不再通过“联网/官网”等正则路由。

| 来源 | 第一版覆盖范围 |
| --- | --- |
| Wiki | 官网站内搜索；优先中文原文，无翻译时读原文语言 |
| 新闻 | 选定年份的标题索引和最近 21 篇摘要，可读取搜索结果的完整原文 |
| 更新日志 | 所选频道最近 21 个构建，区分 lazer、stable40、cuttingedge、beta、web；已知旧链接可直接阅读 |
| 谱面 | 官方谱面库搜索与谱面集详情，可指定规则集 |
| 公开论坛 | 指定板块近期主题标题；主题开头或最近至多 10 帖，保留作者、帖子 ID 与时间。玩家观点不等于官方结论 |

新闻、更新日志与论坛不提供历年全文搜索；工具会返回覆盖范围与时间，“没有匹配结果”不能当作事件不存在的证据。论坛读取通过现有公开 osu! API，`search_osu` 选择 `kind=forum` 并提供 `forumId`；`read_osu` 的 `latest=true` 读取主题后续。不访问第三方社区或代用户发帖。

可在「社交 → Pippi 的近况与经历」独立开启自主阅读，新安装默认关闭。后台先采集列表，再让 Pippi 选择是否阅读；默认最多 3 次/日、至少间隔 4 小时、每日 30,000 Token。它使用相同工具，但每次活动最多 2 次工具、3 次模型请求，包含分享；详见 [人格与经历实现](PIPPI_PERSONALITY.md)。

每轮检索、阅读合计最多 4 次，同时受原有工具预算限制。每次请求总期限 15 秒、响应上限 2 MiB，原文最多返回 18,000 字符并标注截断；只接受指定类型的 `https://osu.ppy.sh` 链接，不跟随重定向。进程内缓存最多 48 条，Wiki 20 分钟，其他资料 3 分钟，不新增磁盘索引。

复用 `searchLogs` 保存成功、失败、耗时及参数哈希，最多 200 条，不在搜索日志中保存完整检索词或正文。`npm run osu:search:verify` 使用独立临时数据与本地模拟服务，验证搜索、原文、地址限制、超时、大小限制及实际聊天工具链；已加入 `npm run check`。

接口参考：[osu! API v2 官方文档](https://osu.ppy.sh/docs/index.html)。
