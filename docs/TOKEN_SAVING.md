# 节能模式

总览页的“开启节能模式”按钮切换 `tokenSavingMode`，保存后立即生效。新安装默认关闭。该模式减少上下文和自动调用频率，原有的普通模式配置仍保留，关闭后恢复。

## 使用差异

聊天使用精简人格和较短历史，一次生成同时选择文字与表情。自然接话只进行较小的参与判断，不在这个判断中写入好感、熟悉程度或自身经历。明确 @ 和允许的私聊请求可直接进入回复；正在进行的对话仍受权限和发送频率约束。

模型聊天期间不提供 osu!、联网、图片或自我查询工具，也不进入工具循环。明确指令如 `/w info` 仍走原来的处理路径。本轮实际图片输入保留，自动图片记忆摘要、后台自主阅读、升级短句和表情失败润色暂停。

历史最多使用 8 条、约 2,200 字符；当前请求和直接引用另行保留。个人记忆与近况也会缩减。已有关系与经历不会因开启节能而清空。

## 画像更新

| 项目 | 节能时的条件 |
| --- | --- |
| 首次个人画像 | 至少 50 条可用记录，且不低于原门槛的 5 倍 |
| 后续个人画像 | 至少 240 条新增可用记录，且不低于原门槛的 8 倍 |
| 群画像 | 原门槛的 4 倍，且至少 200 条 |
| 群友关系画像 | 100 次互动候选计数 |
| 自动更新间隔 | 至少 12 小时 |

样本继续积累，Owner 仍可手动更新。自动补偿扫描暂停，新增交流会触发到期检查。失败保留旧画像和未处理证据，尝试时间会保存，避免重启后立即重复调用。

## 请求限制

节能模式关闭 SDK 自动重试和空输出重试，将自动 high/max 推理降低到 low。普通回复没有统一的 2,048 Token 硬上限；参与判断、自主活动等调用可以各自声明输出长度。具体有效长度由调用方、配置及模型通道决定。

Codex 适配器不提供精确输出 Token 上限的硬控制。项目通过调用次数、超时和上下文控制请求；供应商的计费与账号限制另行处理。

收到 HTTP 401、402、403 或供应商明确的认证/余额错误时，同一 API 配置在 10 分钟内停止重复调用。更改相关连接配置后可重新尝试；不会根据聊天文字推断账号余额。
