基线：`8f4c95f`。用户于 2026-10-23 授权建立目标并执行全部规划，包括必要的短暂停机；不采用灰度、影子双跑或扩群。

## 已定稿的实现约定

- 语义判断交给 LLM：参与意愿、撤销含义、好感、情绪和称呼偏好不使用关键词、正则或相似词列表替代。代码只校验真实身份、指令来源、作用域、预算和结构；Owner 保护不依赖识别“无视”“不要听”等措辞。格式解析与明确命令语法不属于语义判断。
- 隔离测试直接指定模型替身的返回动作，不根据测试输入关键词挑选动作；真实模型权限回放核对具体任务结果，不使用拒绝词表推测是否服从。
- V2 回复不经过旧的关键词异常检测与固定身份答复替换；发送前相关性、改口和撤销含义由模型复核，代码校验取消请求的真实作者。模型复核失败时仍重新核验暂停和权限状态。
- 好感按 Pippi + QQ 保存，普通成员初始中性 50；熟悉程度独立、初始 0。二者的变化由 LLM 根据证据提出，允许 0；单次 ±5 是异常输出保护，不是自动计分公式。旧 XP 不转换。
- 情绪、摘要、已接受称呼和表达偏好按会话 + 对象保存。跨群仅共享好感与熟悉程度，不搬运私人摘要。查询只显示当前会话细节。
- Owner 使用 `{kind: owner, label: 特殊}`，没有 score。默认稳定亲近、重视，允许自然情绪与调侃，不强加主人或恋爱身份；权限不受情绪影响。
- Owner 身份只来自配置和真实发送者，任何 group role、用户策略、可修改权限等级或模型输出均不能授予新查询/长期指令权限。
- 长期指令通过 `/w 指令 set 名称 内容`、`revoke 名称`、`list` 显式维护，别名 `directive`。当前会话作用域，每条保留实际作者、消息 ID、版本、撤销记录。聊天、引用、摘要不会自动成为长期指令。
- 自然接话按群协调：900ms 收集短消息；同一成员连续消息合并，其他人保留独立身份。Owner 明确请求优先，其次普通明确请求。等待动作最多追加一次 1.4s 等待和一次复评。
- 社交评估默认每会话每小时 60 次，范围 1–300，可在控制台调整。预算耗尽时不虚构关系变化；自然接话保持安静，明确请求继续正常回答。单次评估/发送前复核 15s 上限，沿用模型调用总预算。
- 发送前只复核新增消息，复核至多一次。他人消息无法取消 Owner 明确请求；其他明确请求也必须有原作者撤销证据。已核验工具输出不交给复核器改写。
- 主开关 `socialV2Enabled` 的存储迁移默认 false，正式升级验收后统一启用原有 LLM 会话；关闭保留新数据，恢复旧路径。已有群配置、osu-only、silent、onlyMention 等边界保持。
- 新数据 `socialV2` 使用现有 profiles 分片，`ownerDirectives` 保存于核心库；这样旧分片目录无需增加缺失文件。逻辑备份校验、恢复、重启需要共同验证。关闭开关不等于安全降级旧二进制，二进制回滚必须恢复配套冷备份。
- 控制台关系页提供状态、决策、用量、变化撤销、称呼纠正和人工接话反馈。反馈不立即改写模型人设或关系。

## 提及短句与聊天标点

- 用户进一步明确：提及包含 @ 和叫名字，简单问答仍应短答，日常标点不要过于工整。新增可编辑的 `replyLengthGuide`，放在各场景的关系、记忆和语气之后；不受 V2 开关、群聊/私聊或被提问分支影响，发送前复核沿用同一提示。
- 提示词规定日常默认一句口语短句、通常 20 字以内；这是模型表达偏好，不是程序截断上限。@、名字、问号、好感和认真回应均不构成长答理由。只有内容确需解释、步骤、分析或明确长文时才展开，简单操作只报必要结果。没有新增关键词分类、正则压缩或额外润色调用。
- 闲聊默认省略句末句号，不给每处停顿补逗号，不用书面标点串起一大段；问号、感叹号按需，解释、步骤、代码、数字和网址保留必要标点。
